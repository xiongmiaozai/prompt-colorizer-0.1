# 提示词着色插件 — 界面重构方案 v4

> 版本：v4 · 日期：2026-09-02 · 状态：设计规范（待实施）

## 一、概述

### 背景
v3 经多轮迭代后，功能持续叠加导致「颜色」Tab 过载（37 令牌 + 颜色模式 + 文件类型 + 自定义文本 + 配置管理），而「高亮规则」Tab 仅剩开关列表，内容单薄。令牌与开关的关联分散在两个 Tab，认知断裂。

### 目标
1. **功能聚合**：关联功能同 Tab，减少跨页跳转
2. **层级清晰**：全局设置 → 规则控制 → 颜色定义 → 配置管理
3. **快速定位**：搜索 + 折叠 + 分组
4. **视觉降噪**：卡片密度优化，留白规范

---

## 二、问题诊断

| # | 问题 | 表现 | 影响 |
|---|------|------|------|
| P1 | 颜色 Tab 过载 | 37 令牌 + 颜色模式 + 文件类型 + 自定义文本 + 配置管理，5 类堆叠 | 滚动长，找功能难 |
| P2 | 高亮规则 Tab 单薄 | 仅开关列表，无颜色控制 | 内容空旷 |
| P3 | 令牌↔开关关联断裂 | 令牌 chip 在颜色 Tab，开关列表在高亮规则 Tab | 跨 Tab 认知负担 |
| P4 | 核心设置分散 | 编辑器/文件/阅读模式在概览，颜色模式在颜色 Tab | 语义割裂 |
| P5 | 缺少快速定位 | 37 令牌 + 24 开关无搜索 | 配置效率低 |
| P6 | 智能体预设孤立 | 预设与令牌颜色/开关的关系不可见 | 预设不直观 |

## 三、信息架构（5 Tab）

```
概览 │ 着色规则 │ 颜色管理 │ 规则引擎 │ 文件与显示
```

### Tab 1：概览（轻量入口）
- 状态总览条（启用状态 / 规则源 / 令牌数）
- 智能体预设卡片（4 内置 + 自定义，卡片式选择）
- 实时效果预览（**可编辑预览文本**）
- 核心开关卡片（编辑器高亮 / 文件着色 / 阅读模式 / 颜色模式 / 语言）

### Tab 2：着色规则（开关 + 令牌联动，同 Tab）
- **顶部搜索框**：模糊匹配开关名 / 令牌名
- **高亮开关区**（4 折叠分组）：每个开关旁只读色块 + 联动颜色选择器
- **令牌卡片区**（4 折叠分组）：每令牌 toggle + 颜色选择器 + 关联开关 chip
- 开关↔令牌双向联动同页可见，无需跳转

### Tab 3：颜色管理（纯颜色相关）
- 颜色模式（auto / light / dark）
- 文件类型颜色（含重置）
- 自定义文本颜色（总开关 + 浮动面板设置 + 规则列表）
- 配置管理（导出 / 导入）

### Tab 4：规则引擎（不变）
- 规则源 + Git + 拉取报告

### Tab 5：文件与显示（不变）
- 文件检测 + 显示选项

## 六、视觉规范

### 卡片
- 圆角：12px
- 边框：1px solid `var(--background-modifier-border)`
- 阴影：`0 2px 8px rgba(0,0,0,0.06)`
- padding：12px（舒适）/ 10px（紧凑）

### 色块
- 尺寸：28×28
- 圆角：6px
- hover：scale(1.1) + 阴影
- active：2px 边框 + 勾选标记

### 折叠分组
- 标题：14px semibold
- chevron：旋转 90° 过渡 160ms
- 计数徽章：12px muted
- 批量按钮：右对齐，ghost 样式

### 搜索
- 输入框：圆角 8px，左侧搜索图标
- 匹配高亮：背景 `var(--text-highlight-bg)`
- 非匹配：opacity 0.3

### 间距
- 卡片间距：12px
- 卡片内分组间距：8px
- Setting 项间距：默认（Obsidian）
